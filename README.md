# mechanism_project
Программа для комплексного расчёта шарнирного четырёхзвенника

# Установка
```
git clone https://github.com/MahpexM/mechanism_project.git
```
В папке нужно создать виртуальное окружение, активировать его и установить необходимые зависимости. На Windows папка может иметь вид venv/Scripts (см. Интернет):
```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
После установки зависимостей, запускаем:
```
python main.py
```
